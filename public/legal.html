🔒 プライバシーポリシー / Privacy Policy

最終更新日 / Last Updated: 2025年5月17日

釣りナビ PRO（以下「本アプリ」）は、重松テック（個人事業主・重松 Kevin、以下「当社」）が運営する釣り情報サービスです。本ポリシーは、お客様の個人情報の取り扱いについて説明します。

CastWise Japan (釣りナビ PRO) is operated by Shigematsu Tech (sole proprietor Kevin Shigematsu). This policy explains how we handle your personal information.

1. 収集する情報 / Information We Collect

  • 位置情報 (Location): ユーザーが明示的に許可した場合のみ収集します。天気予報・釣り場情報・混雑状況の表示に使用します。
    Collected only when you explicitly grant permission. Used for weather, spot info, and crowding display.
  • 釣果データ (Catch Data): ユーザーが任意で入力した釣果記録（魚種・重量・場所・写真）。Firebase Firestoreに保存されます。
    Catch records you voluntarily enter. Stored in Firebase Firestore.
  • 匿名ID (Anonymous ID): ブラウザのlocalStorageに保存される匿名識別子。アクティブユーザー表示に使用します。氏名・メールアドレス等の個人情報は含みません。
    Anonymous identifier stored in localStorage for active user display. Contains no personal identifiers.
  • プロフィール情報 (Profile): ユーザーが任意で設定したニックネーム・アバター。localStorageに保存されます。
    Nickname and avatar you optionally set. Stored locally in localStorage.

2. 情報の利用目的 / How We Use Your Information

  • 釣り場の天気・潮汐・混雑情報の表示
  • コミュニティ釣果フィードの表示
  • AI釣りアドバイス機能の提供（Anthropic Claude API）
  • サービスの改善および不正利用の防止

3. 第三者サービス / Third-Party Services

本アプリは以下の第三者サービスを利用しており、各社のプライバシーポリシーが適用されます：

  • Google Firebase — データベース・ストレージ（プライバシーポリシー）
  • Google AdSense — 広告配信（プライバシーポリシー）
  • Anthropic Claude API — AI機能（プライバシーポリシー）
  • Amazon Associates — アフィリエイトリンク（プライバシーポリシー）
  • Open-Meteo — 気象データ（利用規約）
  • OpenStreetMap / Nominatim — 地図・逆ジオコーディング（プライバシーポリシー）

4. データの保存期間 / Data Retention

  • アクティブユーザー位置情報：最終更新から10分で自動削除
  • 釣果データ：ユーザーが削除するまで保持
  • localStorageデータ：ブラウザのキャッシュクリアで削除

5. ユーザーの権利 / Your Rights

お客様は以下の権利を有します：

  • 収集した個人情報へのアクセス・修正・削除の請求
  • 位置情報共有のいつでもオフ（アプリ内トグルまたはブラウザ設定）
  • データ削除の請求（下記お問い合わせ先へ）

6. 未成年者 / Minors

本アプリは13歳未満の方を対象としていません。13歳未満の方の個人情報を意図的に収集することはありません。

7. ポリシーの変更 / Changes to This Policy

本ポリシーを変更する場合、本ページに掲載し最終更新日を更新します。重要な変更がある場合はアプリ内でお知らせします。
